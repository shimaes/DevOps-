
آموزش گرفتن DNS یک سایت

برای اینکه بفهمیم یک سایت (دامنه) چه رکوردهای DNS دارد (مثل IP، ایمیل سرورها یا نام‌سرورها)، می‌توانیم از دستورات زیر در اوبونتو استفاده کنیم:

dig +short example.com A     # آدرس IPv4
dig +short example.com MX    # رکوردهای ایمیل
dig +short example.com NS    # نام‌سرورها

اگر ابزار dig نصب نبود:

sudo apt install dnsutils

این دستورات کمک می‌کنند DNSهای اصلی یک سایت را به سادگی ببینیم.
